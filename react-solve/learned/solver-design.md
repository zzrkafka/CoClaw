# Solver-design insights

This file stores transferable design insights, supported by task evidence and approved by review, that primarily help a future Agent construct a stronger solver on the first attempt or repair an existing solver more effectively. Content may concern representation, implementation, search, and within-instance scheduling, but it must retain applicability conditions and tradeoffs rather than mapping task features directly to fixed actions.

Search it selectively for the current task and design autonomously from the statement, instances, and available tools; when no relevant entry exists, rely on Codex's own intelligence. Keep new entries self-contained and do not store problem-specific code, instance answers, bare parameters, or unverified algorithm lists.
